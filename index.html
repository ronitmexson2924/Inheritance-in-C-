Introduction to Inheritance

What is Inheritance?

Inheritance in C++ is a core OOP concept where a derived class (child) inherits attributes and methods from a base class (parent), enabling code reusability and logical hierarchies. It represents an "is-a" relationship between classes, allowing developers to extend functionality without duplicating code.

Real-World Analogy

Think of inheritance like genetic inheritance in families. Just as children inherit traits from their parents, derived classes inherit attributes and methods from base classes.

Parent Class

  • Attributes
  • Methods
  • Properties
↓

Child Class

  • Inherited Elements
  • + New Attributes
  • + New Methods

Benefits of Inheritance

  • Code Reusability: Reuse attributes and methods of existing classes
  • Reduced Redundancy: Avoid duplicating code across multiple classes
  • Extensibility: Extend functionality of existing classes without modifying them
  • Hierarchical Classification: Create logical class hierarchies that model real-world relationships
  • Transitive Nature: If class C inherits from B, and B inherits from A, then C inherits from A

Types of Inheritance

Single Inheritance

A derived class inherits from only one base class. This is the simplest form of inheritance.


// Single Inheritance Example
class Vehicle {
protected:
    string brand = "Unknown";
    
public:
    void honk() {
        cout << "Tuut, tuut!" << endl;
    }
};

class Car : public Vehicle {
private:
    string model = "Unknown";
    
public:
    void display() {
        cout << "Brand: " << brand << ", Model: " << model << endl;
    }
};

Multiple Inheritance

A derived class inherits from two or more base classes. This allows combining functionality from different sources.


// Multiple Inheritance Example
class Engine {
public:
    void start() {
        cout << "Engine started" << endl;
    }
};

class Wheels {
public:
    void rotate() {
        cout << "Wheels rotating" << endl;
    }
};

class Car : public Engine, public Wheels {
public:
    void drive() {
        start();  // From Engine
        rotate(); // From Wheels
        cout << "Car is moving" << endl;
    }
};

Multilevel Inheritance

A derived class inherits from a base class, which in turn inherits from another base class, forming a chain of inheritance.


// Multilevel Inheritance Example
class Animal {
public:
    void eat() {
        cout << "Animal is eating" << endl;
    }
};

class Mammal : public Animal {
public:
    void breathe() {
        cout << "Mammal is breathing" << endl;
    }
};

class Dog : public Mammal {
public:
    void bark() {
        cout << "Dog is barking" << endl;
    }

    void showAbilities() {
        eat();      // From Animal (grandparent)
        breathe();  // From Mammal (parent)
        bark();     // Own method
    }
};

Hierarchical Inheritance

Multiple derived classes inherit from a single base class, creating a hierarchy where each derived class has its own specialized functionality.


// Hierarchical Inheritance Example
class Shape {
protected:
    double area;
public:
    void displayArea() {
        cout << "Area: " << area << endl;
    }
};

class Circle : public Shape {
private:
    double radius;
public:
    Circle(double r) : radius(r) {
        area = 3.14159 * radius * radius;
    }

    void displayType() {
        cout << "This is a Circle" << endl;
    }
};

class Rectangle : public Shape {
private:
    double length, width;
public:
    Rectangle(double l, double w) : length(l), width(w) {
        area = length * width;
    }

    void displayType() {
        cout << "This is a Rectangle" << endl;
    }
};

class Triangle : public Shape {
private:
    double base, height;
public:
    Triangle(double b, double h) : base(b), height(h) {
        area = 0.5 * base * height;
    }

    void displayType() {
        cout << "This is a Triangle" << endl;
    }
};

Common Problems in Inheritance

The Diamond Problem

The diamond problem occurs when a class inherits from two classes that both inherit from a common base class, creating ambiguity about which version of the base class's members to use.

In this example, AmphibiousVehicle inherits from both Car and Boat, which both inherit from Vehicle. Without virtual inheritance, AmphibiousVehicle would contain two separate Vehicle instances, causing ambiguity. Using virtual inheritance ensures only one Vehicle instance exists in the hierarchy.


// Diamond Problem Example    
#include <iostream>
using namespace std;

class Vehicle {
protected:
    string registrationNumber;
public:
    Vehicle(string reg = "UNKNOWN") : registrationNumber(reg) {
        cout << "Vehicle constructor called" << endl;
    }
    
    virtual void startEngine() {
        cout << "Vehicle engine starting..." << endl;
    }
    
    void displayRegistration() {
        cout << "Registration Number: " << registrationNumber << endl;
    }
    
    virtual ~Vehicle() {
        cout << "Vehicle destructor called" << endl;
    }
};

class Car : virtual public Vehicle {
protected:
    int numDoors;
public:
    Car(string reg = "CAR-REG", int doors = 4) : Vehicle(reg), numDoors(doors) {
        cout << "Car constructor called" << endl;
    }
    
    void startEngine() override {
        cout << "Car engine starting with key turn..." << endl;
    }
    
    void drive() {
        cout << "Car driving on road" << endl;
    }
    
    ~Car() {
        cout << "Car destructor called" << endl;
    }
};

class Boat : virtual public Vehicle {
protected:
    int propellerCount;
public:
    Boat(string reg = "BOAT-REG", int propellers = 1) : Vehicle(reg), propellerCount(propellers) {
        cout << "Boat constructor called" << endl;
    }
    
    void startEngine() override {
        cout << "Boat engine starting with push button..." << endl;
    }
    
    void sail() {
        cout << "Boat sailing on water" << endl;
    }
    
    ~Boat() {
        cout << "Boat destructor called" << endl;
    }
};

class AmphibiousVehicle : public Car, public Boat {
private:
    bool isInWaterMode;
public:
    AmphibiousVehicle(string reg = "AMPHI-REG", int doors = 2, int propellers = 2) 
        : Vehicle(reg), Car(reg + "-CAR", doors), Boat(reg + "-BOAT", propellers), isInWaterMode(false) {
        cout << "AmphibiousVehicle constructor called" << endl;
    }
    
    void startEngine() {
        if (isInWaterMode) {
            Boat::startEngine();
        } else {
            Car::startEngine();
        }
    }
    
    void toggleMode() {
        isInWaterMode = !isInWaterMode;
        cout << "Switching to " << (isInWaterMode ? "water" : "land") << " mode" << endl;
    }
    
    void displayRegistration() {
        cout << "Amphibious Vehicle Registrations:" << endl;
        cout << "Primary registration: ";
        Vehicle::displayRegistration();
        cout << "Car registration: " << Car::registrationNumber << endl;
        cout << "Boat registration: " << Boat::registrationNumber << endl;
    }
    
    ~AmphibiousVehicle() {
        cout << "AmphibiousVehicle destructor called" << endl;
    }
};

int main() {
    cout << "Creating an amphibious vehicle..." << endl;
    AmphibiousVehicle amphibious("AV-123");
    
    cout << "\nCalling methods on the amphibious vehicle:" << endl;
    amphibious.startEngine();
    amphibious.displayRegistration();
    
    cout << "\nChanging mode and starting engine again:" << endl;
    amphibious.toggleMode();
    amphibious.startEngine();
    
    cout << "\nAccessing Vehicle methods directly is now possible:" << endl;
    amphibious.Vehicle::startEngine();
    
    cout << "\nDestroying the amphibious vehicle..." << endl;
    return 0;
}

Solution to the Diamond Problem

The diamond problem is solved in C++ using virtual inheritance. When a class is virtually inherited, only one instance of the base class exists in the inheritance hierarchy, regardless of how many inheritance paths exist to it.

Key points about virtual inheritance:

  • Single Base Class Instance: Only one copy of the base class exists in the final derived class
  • Constructor Initialization: The most derived class must initialize virtual base classes directly
  • Memory Efficiency: Reduces memory usage by avoiding duplicate base class members
  • Ambiguity Resolution: Eliminates the need to specify which inheritance path to use when accessing base class members

Without virtual inheritance, the code would not compile due to ambiguity errors when trying to access members of the Vehicle class from the AmphibiousVehicle class.

Slicing Problem

The slicing problem occurs when a derived class object is assigned to a base class object, causing the derived class-specific members to be "sliced off" and lost.


// Slicing Problem Example
class Base {
protected:
    int baseValue;
public:
    Base(int val = 0) : baseValue(val) {}
    virtual void display() {
        cout << "Base value: " << baseValue << endl;
    }
};

class Derived : public Base {
private:
    int derivedValue;
public:
    Derived(int bVal = 0, int dVal = 0) : Base(bVal), derivedValue(dVal) {}
    void display() override {
        Base::display();
        cout << "Derived value: " << derivedValue << endl;
    }
};

int main() {
    Derived d(10, 20);
    Base b = d;  // Slicing occurs here - derivedValue is lost
    
    d.display();  // Shows both values
    b.display();  // Only shows baseValue, calls Base::display()
    
    return 0;
}

To avoid slicing, use pointers or references to base class types when working with polymorphism:

    
Base* ptr = &d;     // No slicing
Base& ref = d;      // No slicing
ptr->display();     // Calls Derived::display()
ref.display();      // Calls Derived::display()
